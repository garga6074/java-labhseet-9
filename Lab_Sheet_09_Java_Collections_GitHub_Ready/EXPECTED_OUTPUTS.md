# Expected Output Guide

Exact formatting may vary slightly by Java version.

| Exercise | Expected observation |
|---:|---|
| 1 | Prints all integer ArrayList elements |
| 2 | Displays the number of elements in the list |
| 3 | New element appears at the requested index |
| 4 | Removes one item by index and first matching item by value |
| 5 | `set()` replaces the item at the specified index |
| 6–7 | Elements are printed sequentially using two iteration methods |
| 8 | Integers print in ascending order |
| 9 | String list is reversed |
| 10–13 | LinkedList displays, adds, removes and retrieves end elements |
| 14–16 | HashSet stores unique elements; its iteration order is unspecified |
| 17 | TreeSet prints values in ascending order |
| 18 | `contains()` prints true for the selected existing value |
| 19 | LinkedHashSet keeps the first insertion order and ignores duplicates |
| 20 | Shows unspecified HashSet order, insertion-ordered LinkedHashSet and sorted TreeSet |
| 21–23 | PriorityQueue head is the smallest integer; repeated removals produce priority order |
| 24–25 | Queue demonstrates FIFO add/remove/peek behavior |
| 26 | Iterator prints Student objects |
| 27 | Comparator sorts Student objects by grade, highest first |
| 28 | List-to-Set conversion removes duplicates |
| 29 | Set values are copied into a List and iterated |
| 30 | List, Set and Queue are empty after `clear()` |

**Note:** Do not use the printed internal representation of a PriorityQueue as evidence of sorted order. To observe priority order, repeatedly remove or poll its head.
